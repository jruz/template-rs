# template-rust

A minimal Rust CLI template using Clap.

## Development

- `just run`
- `just check`
- `just test`
- `just install`

## Nix installation

- `nix profile add github:jruz/template-rust` installs the latest release binary.
- `nix profile add github:jruz/template-rust#source` builds from source.
